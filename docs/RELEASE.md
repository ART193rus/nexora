# Выпуск Nexora: сборка, подпись, публикация

## 1. Версия
Поднять номер в двух местах: `desktop/Cargo.toml` (`version`) и `desktop/tauri.conf.json` (`version`). Формат `1.2.3`.

## 2. Сборка установщика
```
cd desktop
set PATH=%USERPROFILE%\.cargo\bin;%PATH%
set CARGO_TARGET_DIR=target-pack
cargo test --release
cargo tauri build
```
Результат: `target-pack\release\bundle\nsis\Nexora_<версия>_x64-setup.exe`.
В установщик входит движок из `desktop/pack/engine/` (llama-server и библиотеки, около 45 МБ, см. README в этой папке). Модели не входят.
Установка для всех пользователей в `Program Files\Nexora` (запрашивает права администратора один раз), данные пользователя
лежат отдельно в `%LOCALAPPDATA%\Nexora` и при обновлении и удалении программы не трогаются.

## 3. Свой ключ подписи обновлений
Проверка обновлений использует открытый ключ Ed25519, вшитый в `desktop/src/update.rs` (`UPDATE_PUBKEY_B64`).
Вшитый в репозитории ключ принадлежит автору проекта, **для своей сборки сгенерируйте свою пару**:
```
nexora.exe --gen-update-key <файл-закрытого-ключа> <файл-открытого-ключа>
```
Открытый ключ (base64) впишите в `UPDATE_PUBKEY_B64` и пересоберите. **Закрытый ключ храните только у себя**, в репозиторий и в облако не класть,
сделать копию в надёжное место. Потеря ключа: нельзя выпускать обновления для уже установленных копий. Утечка: перевыпуск программы
с новым открытым ключом.

## 4. Подпись обновления
```
nexora.exe --sign-update <setup.exe> <версия> <https-адрес-setup.exe> <закрытый-ключ> <latest.json> "что нового"
```
Результат в `<latest.json>`; рядом файл `<latest.json>.log` со словом `ok` или причиной ошибки (у релизной сборки нет консоли).

## 5. Публикация
Выложить `setup.exe` и `latest.json` на https-хостинг (например, GitHub Releases). Адрес `latest.json` вписывается
пользователем в Настройки, «Обновления». Программа проверяет подпись Ed25519, контрольную сумму файла, https и то, что версия
строго новее. Ничего не ставится без нажатия кнопки.

## 6. Брандмауэр и телефон
Правила Windows привязаны к пути exe. После установки в `Program Files\Nexora` Windows один раз спросит про сеть
(для режима «Сервер»): разрешить для частной сети.

## 7. Перед публичным выпуском
- Заменить иллюстрации в высоком разрешении (если используются).
- Подписать сам установщик сертификатом подписи кода (без него Windows SmartScreen предупреждает «неизвестный издатель»);
  подпись обновлений Ed25519 это отдельная защита и сертификат кода не заменяет.
- Отладочный ход `NEXORA_DEV_EVAL` работает только в отладочной сборке (`debug_assertions`), в релизную не попадает.
