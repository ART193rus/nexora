# Движок llama.cpp

Сюда кладутся файлы движка для установщика (в репозиторий они не входят: около 45 МБ и своя лицензия MIT):

- `llama-server.exe` и необходимые `*.dll` (в том числе `ggml-*.dll`) из Windows-сборки (CPU) релиза
  <https://github.com/ggml-org/llama.cpp/releases>;
- файлы лицензий и `THIRD-PARTY.txt` из того же релиза.

Без этих файлов программа соберётся, но встроенный движок не запустится: тогда можно подключить внешний (Ollama, LM Studio)
в разделе «Модели».
