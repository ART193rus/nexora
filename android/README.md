# Nexora Agent (Android)

Клиент для Nexora Server: пульт для агента, работающего на вашем ПК или мини-ПК. Kotlin + Jetpack Compose + OkHttp, minSdk 29.

## Что умеет
- Чат с агентом на ПК (ответ приходит потоком, ход виден по мере работы), несколько чатов, голосовой ввод, выбор модели ПК.
- Режим «⚡ Быстро»: короткая подсказка без инструментов, на слабом ПК ответ в разы быстрее.
- Список задач с живым ходом, остановка и повтор, подтверждения действий агента (опасные требуют свежий код Authenticator).
- Режим доверенного устройства: обычные подтверждения одобряются на ПК; удаление, администратор и боевой сервер спрашивают всегда.
- Вложение текстовых файлов, сохранение результата, QR-сканер для привязки, уведомления без FCM (foreground-сервис).

## Как это защищено
- Вход по **сертификату устройства** (ключ создаётся в Android Keystore и привязан к биометрии или PIN) плюс TOTP, а не пароль или токен.
- TLS с закреплением сертификата сервера по отпечатку из строки привязки (`nexora://адрес:порт#отпечаток`).
- Рекомендуется подключаться к ПК через VPN (Tailscale или WireGuard); строка привязки содержит адрес, поэтому после смены
  адреса устройство нужно привязать заново.

## Подключение
1. На ПК: Nexora → Настройки → «Сервер» → включить, открыть окно привязки (показывает QR).
2. На телефоне: «Подключить», отсканировать QR или вставить строку `nexora://…`, ввести код из Authenticator.

## Сборка
Нужны JDK 17 и Android SDK (compileSdk 36).
```
./gradlew :app:assembleRelease
```
Без своего ключа сборка подписывается отладочным ключом. Для своей подписи создайте хранилище в `keystore/` и файл
`keystore.properties` (оба в Git не попадают):
```
storeFile=keystore/my.jks
storePassword=...
keyAlias=...
keyPassword=...
```
и собирайте с `-PlocalSign`. Смена подписи требует удаления приложения с телефона.

Тесты: `./gradlew :app:testDebugUnitTest`. Сквозной тест `E2eTest` идёт против настоящего сервера: запустите стенд
`nexora.exe --selftest-host <порт> <файл>` (с `NEXORA_SELFTEST=1`, `LOCALAPPDATA` во временную папку) и задайте
`NEXORA_E2E_INFO=<info.json>`.
