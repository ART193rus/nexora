# Nexora

Локальный ИИ-агент для Windows: чат с моделью, которая работает на вашем компьютере, умеет читать и править файлы,
запускать код и команды, но **только с вашего подтверждения**. Плюс режим сервера для мини-ПК и Android-клиент,
чтобы управлять агентом с телефона.

*English: a lightweight local AI coding agent for Windows (Tauri 2 + Rust, bundled llama.cpp), with a secure
server mode (mTLS + Authenticator code) and an Android client. Early version 0.1.0, documentation is in Russian.*

> Статус: ранняя версия 0.1.0. Рабочая, но не отполированная; список проверенного и непроверенного ниже.

| Папка | Что это |

## Возможности (десктоп)

- **Свои модели.** Встроенный движок [llama.cpp](https://github.com/ggml-org/llama.cpp) (в репозиторий не входит, см. ниже),
  каталог моделей с оценкой «влезет ли в ваш ПК и какая будет скорость», загрузка с Hugging Face
  **параллельными кусками с докачкой**. Можно подключить внешний движок (Ollama, LM Studio, свой сервер).
- **Агент с правами.** Инструменты: чтение, правка (с diff), создание и удаление файлов, запуск команд и приложений.
  Три режима подтверждений; удаление и опасные действия спрашивают всегда. Секретные файлы (`.env`, ключи) недоступны.
- **Проекты на серверах по SSH** с пометкой «боевой» (изменения всегда с подтверждением, секреты в выводе скрыты).
- **Навыки и плагины** (SKILL.md), **MCP-серверы**, **веб-поиск**, **управление браузером** (Chrome/Edge), память между чатами,
  задачи по расписанию.
- **Модель знает, где работает.** Если открыть папку исходников Nexora, модель понимает, что правит саму программу;
  модули безопасности (`secure`, `pki`, `totp`, `update`, `server`, `tools`, `agent` и др.) защищены от её правки
  на уровне инструментов, перед правкой делается копия файла.
- **Лёгкость.** Один небольшой exe, без Python и Node в рантайме.

## Режим сервера и телефон

Одна программа работает в двух режимах (Настройки → Режим работы):

- **Пользователь** (по умолчанию): никакого сетевого слушателя вообще. Движок слушает только `127.0.0.1` на случайном
  порту с токеном сессии.
- **Сервер**: программа принимает подключения других ваших устройств. Вход только по **клиентскому сертификату устройства (mTLS)**
  плюс **код из Google Authenticator (TOTP)**; привязка нового устройства идёт через временное «окно привязки».
  Опасные подтверждения (удаление, права администратора, боевой сервер) требуют свежий код.

Доступ из интернета рекомендуется только через VPN ([Tailscale](https://tailscale.com) или WireGuard), без открытого порта.
VPN в программу не встроен. Подробности: [`docs/SECURITY.md`](docs/SECURITY.md).

### Android-клиент (Nexora Agent)

Пульт для агента на вашем ПК или мини-ПК: чат, голосовой ввод, несколько чатов, выбор модели ПК, список задач с живым ходом,
подтверждения действий, вложение текстовых файлов, режим «⚡ Быстро». Ключ устройства хранится в Android Keystore
и привязан к биометрии или PIN. Подробности и сборка: [`android/README.md`](android/README.md).

## Сборка десктопа

Нужны Windows 10+, [Rust](https://rustup.rs) и Visual Studio Build Tools (C++).

1. Положите движок llama.cpp (Windows, CPU-сборка: `llama-server.exe` и `ggml-*.dll`) в [`desktop/pack/engine/`](desktop/pack/engine).
2. Тесты и сборка:
   ```
   cd desktop
   cargo test --release
   cargo build --release          # nexora.exe
   cargo tauri build              # установщик NSIS (нужен cargo-tauri)
   ```
Пока программа открыта, exe заблокирован: собирайте в другую папку (`set CARGO_TARGET_DIR=target-new`).
Выпуск, подпись обновлений: [`docs/RELEASE.md`](docs/RELEASE.md).

## Проверено и не проверено

Честно о состоянии версии 0.1.0:

- Автотесты: ядро (пути, права, сертификаты, TOTP, сервер, загрузка, плагины, MCP на поддельном сервере и т. д.).
- Проверено вручную: чат с локальной моделью, режим сервера, привязка и работа Android-клиента на реальном телефоне,
  параллельная загрузка моделей.
- **Не проверено или с оговорками:** MCP на настоящих серверах из npm/uvx; управление браузером (зависит от политик Windows,
  в частности `RemoteDebuggingAllowed`); UAC-запросы вручную; установщик не подписан сертификатом подписи кода
  (Windows SmartScreen предупредит об «неизвестном издателе»); встроенный ключ проверки обновлений принадлежит
  автору проекта: для своей сборки сгенерируйте свою пару (см. `docs/RELEASE.md`).
- Модель не безошибочна, а подтверждения остаются последним барьером: читайте команды перед тем, как разрешить.
